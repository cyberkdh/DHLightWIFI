# README usage flow 정리

## 배경

- `README` 의 기존 quick start 예제는 핵심은 맞았지만, 처음 보는 사용자 입장에서
  어떤 연결 방식(connect flow)을 선택해야 하는지 한 번에 판단하기 어려웠다.

## 이번 정리 내용

- `DHWifiClient2` 를 권장 진입점(recommended entry point)으로 명시
- 예제를 역할별로 분리
  - basic connect
  - direct SSID-first connect
  - saved profile reconnect
  - hidden network
  - Enterprise (`802.1X`)
  - EAP-TLS
- `...AndWait(...)` 계열이 새 코드(new code)의 기본 패턴이라는 점을 재강조
- `WaitForConnectionResult(...)` 와 `Notification` 이벤트(event)는 lower-level control 용도로 위치를 내림

## 의도

- NuGet 사용자가 `README` 만 보고도 바로 자신의 시나리오에 맞는 시작점을 찾게 한다.
- `DHWifiClient2` 의 사용성이 "단순 연결뿐 아니라 전체 흐름을 다룰 수 있다"는 점이 자연스럽게 드러나게 한다.
