# README API name sync 정리

## 발견 내용

- `README` 의 `Supported authentication methods` 표 일부가 예전 저수준(low-level) `Connect(...)` 표기를 유지하고 있었다.
- 현재 `DHWifiClient2` 공개 표면(public surface) 기준으로 보면 다음 표기는 정확하지 않았다.
  - `Connect(ssid)`
  - `Connect(ssid, password)`
  - `Connect(ssid, password, protocol, cipher)`

## 조치

- 표를 `DHWifiClient2` 기준으로 다시 맞췄다.
- `ConnectOpen(...)`
- `ConnectPersonal(...)`
- `ConnectSavedProfile(...)`
- hidden network 계열
- `...AndWait(...)` 계열
- `Connect(WifiNetwork, password)` 자동 감지(auto-detect) 경로

## 의도

- 문서(documentation)와 실제 API 이름(API name)이 100% 일치하도록 맞춘다.
- `DHWifiClient2` 와 기존 저수준(low-level) `DHWifiClient` / `WifiInterface` 표기를 혼동하지 않게 한다.
