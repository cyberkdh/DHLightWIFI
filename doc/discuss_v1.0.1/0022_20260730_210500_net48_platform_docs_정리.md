# net48 / platform docs 정리

## 배경

- 라이브러리(library)와 샘플(sample) 프로젝트 파일에는 `net48` 지원이 이미 반영되어 있다.
- 다만 `README` 의 샘플 설명(sample description)에서는 멀티 타깃(multi-target)과 실행 플랫폼(executable platform) 안내가 상대적으로 덜 선명했다.

## 이번 정리

- `README` 의 requirements 섹션에서 sample executable 전반이 `x64` 기본 + `x86` 제공이라는 점을 명확히 함
- 각 sample 설명에 아래를 직접 표기
  - `net46`, `net48`, `net6.0-windows`, `net8.0-windows`
  - `x86` / `x64` executable build
  - default platform = `x64`
- sample platform notes 에도 위 내용을 한 번 더 모아서 표기

## 의도

- `net48` 지원 여부가 문서(documentation)만 봐도 바로 보이게 한다.
- `AnyCPU` 는 library 쪽 이야기이고, sample executable 은 `x86` / `x64` 라는 점을 혼동하지 않게 한다.
